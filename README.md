3. comparison of 2 approaches
Row SQL allows developer to directly control execution and can easily test queries in database management for clients end. ORM provides higher level of object portabiluty which allows queries to be integrated into native python cade naturally. Besides, ORM can auto complete and proofread the model which can reduce bugs. However, in my perspective, if we only want to make simple analyze, raw SQL is more concise.
